1 准备工作

提示
所有 ARM64 兼容性修复和 Python 包结构修复已内置在本仓库的 Dockerfile 和代码中，直接照做即可。

1.1 克隆代码

cd ~
git clone <仓库地址> xlerobot-sim2real
cd ~/xlerobot-sim2real

1.2 创建 Isaac Sim 缓存目录

mkdir -p ~/docker/isaac-sim/cache/{kit,ov,pip,glcache,computecache}
mkdir -p ~/docker/isaac-sim/{logs,data,documents}
Docker 容器关闭后内部数据丢失。挂载缓存到主机后，Isaac Sim 下次启动不用重新编译着色器。

1.3 创建输出和数据集目录

mkdir -p ~/xlerobot-sim2real/Sim-to-Real-SO-101-Workshop-main/outputs
mkdir -p ~/xlerobot-sim2real/Sim-to-Real-SO-101-Workshop-main/datasets

1.4 配置机器人端口（有真机时）

# 编辑机器人配置文件
nano ~/xlerobot-sim2real/Sim-to-Real-SO-101-Workshop-main/docker/env
docker/env 文件内容 
export LEROBOT_CALIB=.cache/huggingface/lerobot/calibration
export TELEOP_PORT=/dev/ttyACM1    # 领导臂 USB 端口
export ROBOT_PORT=/dev/ttyACM0     # 被控臂 USB 端口
export TELEOP_ID=orange_teleop     # 领导臂标识名
export ROBOT_ID=orange_robot       # 被控臂标识名
export CAMERA_GRIPPER=0            # 夹爪摄像头编号

方式二：手动完整命令

展开完整 docker run 命令及逐行解释 
xhost +                # 允许容器访问显示器
PROJECT_ROOT="$(cd .. && pwd)"

docker run --name teleop -it --privileged --gpus all \
  -e "ACCEPT_EULA=Y" \                        # 接受 NVIDIA 许可协议
  -e "PRIVACY_CONSENT=Y" \                     # 接受隐私政策
  -e DISPLAY \                                 # GUI 窗口显示
  -e LD_PRELOAD=/usr/lib/aarch64-linux-gnu/libgomp.so.1 \  # ARM64 TLS 修复
  -e GLIBC_TUNABLES=glibc.rtld.optional_static_tls=2048 \  # ARM64 TLS 修复
  --rm --network=host \
  -v /dev:/dev \                               # USB 设备访问
  -v /run/udev:/run/udev:ro \
  -v "$HOME/.Xauthority:/root/.Xauthority" \   # X11 认证
  -v "$HOME/docker/isaac-sim/cache/kit:/isaac-sim/kit/cache:rw" \
  -v "$HOME/docker/isaac-sim/cache/ov:/root/.cache/ov:rw" \
  -v "$HOME/docker/isaac-sim/cache/pip:/root/.cache/pip:rw" \
  -v "$HOME/docker/isaac-sim/cache/glcache:/root/.cache/nvidia/GLCache:rw" \
  -v "$HOME/docker/isaac-sim/cache/computecache:/root/.nv/ComputeCache:rw" \
  -v "$HOME/docker/isaac-sim/logs:/root/.nvidia-omniverse/logs:rw" \
  -v "$HOME/docker/isaac-sim/data:/root/.local/share/ov/data:rw" \
  -v "$HOME/docker/isaac-sim/documents:/root/Documents:rw" \
  -v "$HOME/.cache/huggingface/lerobot/calibration:/root/.cache/huggingface/lerobot/calibration" \
  -v "$(pwd)/docker/env:/root/env" \
  -v "$(pwd)/source:/workspace/Sim-to-Real-SO-101-Workshop/source" \
  -v "$(pwd)/outputs:/workspace/Sim-to-Real-SO-101-Workshop/outputs" \
  -v "$(pwd)/datasets:/workspace/Sim-to-Real-SO-101-Workshop/datasets" \
  -v "$PROJECT_ROOT/source/xlerobot_tasks:/workspace/xlerobot_tasks" \   # XLeRobot 源码
  -v "$PROJECT_ROOT/assets:/workspace/xlerobot_assets" \                 # 3D 模型
  -e XLEROBOT_ASSETS_ROOT=/workspace/xlerobot_assets \                   # 资产路径
  teleop-docker:latest
容器启动后 entrypoint.sh 自动安装 sim_to_real_so101 和 xlerobot_tasks，无需手动操作。

所有修复已内置在代码中。详见 docs/FIXES.md。

ARM64 平台修复

#问题N1.6N1.7
1torchcodec 版本不存在pin >=0.11.0pin >=0.10.0 (已有 ARM64)
2CUDA PyTorch 被 CPU 版替换动态捕获基础镜像版本（两版通用）
3triton 版本不存在从 pyproject.toml 删除（两版通用）
4TLS 内存不足崩溃LD_PRELOAD + GLIBC_TUNABLES（两版通用）
5FFmpeg 架构错误使用 linuxarm64 构建（两版通用）
6GR00T Python 版本需要 3.10 + 隐藏 wheel支持 3.12，无需额外 wheel

Python 包结构修复

7xlerobot_tasks.assets 模块缺失新建 assets/*.py
8setup.py 只声明顶层包改用 find_packages()
9sim_to_real_so101 缺少 __init__.py新建 __init__.py
10scripts/ 缺少 __init__.py新建 __init__.py

常见报错

cannot allocate memory in static TLS block
原因：ARM64 TLS 空间不足
解决：加 LD_PRELOAD 和 GLIBC_TUNABLES 环境变量（脚本已自动配置）
torch.cuda.is_available() 返回 False
原因：CUDA PyTorch 被 CPU 版替换
解决：使用 Dockerfile.arm64 重新构建
No matching distribution found for torchcodec
原因：ARM64 包版本不同
解决：已在 Dockerfile.arm64 中修复
ImportError: xlerobot_tasks.assets.xlerobot
原因：原仓库缺少 assets 模块
解决：本仓库已新建；确认用的是修复版代码
ModuleNotFoundError: sim_to_real_so101
原因：缺少 __init__.py
解决：本仓库已新建 __init__.py
import xlerobot_tasks 失败（容器内）
原因：容器没挂载 xlerobot_tasks
解决：使用 ./run_teleop_arm64.sh 启动（自动挂载）
Isaac Sim 启动很慢（>5 分钟）
原因：首次需编译着色器
解决：正常现象，缓存挂载后第二次会快很多
没有 GUI 窗口弹出
原因：X11 转发没配置
解决：确认运行了 xhost + 并传入了 -e DISPLAY
